**Status vocabulary** (each row uses exactly one):

| Status | Meaning |
|---|---|
| PASS | Accepted by the owner, and the accepting decision is quoted in the records. For the PRD rows this is only OD-114 (a) so far. |
| BUILT | Built and verified locally (tests and/or browser checks). Not accepted. |
| PARTIAL | Part of it is built locally and the rest is named. Not accepted. |
| BLOCKED | Cannot be built or verified until a named input, decision or environment exists. |
| NOT BUILT | Within a phase that has started, but nothing has been built for it yet. |
| NOT STARTED | Its phase has not started and nothing has been built for it. |
